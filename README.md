# Lista de Tarefas

Projeto desenvolvido durante o módulo de **Angular** da formação WoMakersCode.

## 📋 Sobre o projeto

Aplicação de lista de tarefas desenvolvida com Angular, permitindo:

- Adicionar novas tarefas
- Marcar tarefas como concluídas
- Excluir tarefas
- Exibir as tarefas cadastradas

## 🛠️ Tecnologias utilizadas

- Angular 21
- TypeScript
- HTML
- CSS
- Node.js
- npm

## ▶️ Como executar o projeto

Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

Entre na pasta:

```bash
cd ListaDeTarefas
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
ng serve
```

Acesse no navegador:

```text
http://localhost:4200
```

Praticar os principais conceitos do Angular, incluindo componentes, data binding, eventos, inputs, outputs e signals.
